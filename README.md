# Игра «Угадай число» (C++)

Консольная игра, в которой программа загадывает случайное число от 1 до 100, а пользователь пытается его угадать.

## Правила игры

1. Программа случайным образом загадывает целое число в диапазоне от 1 до 100.
2. Игрок вводит свой вариант числа.
3. Если введенное число больше или меньше загаданного, программа подсказывает игроку.
4. Игра продолжается до тех пор, пока число не будет угадано.
5. В конце выводится количество затраченных попыток.
6. Для выхода из игры в любой момент необходимо ввести цифру `0`.

## Пример работы

```text
=== Игра 'Угадай число' ===
Я загадал число от 1 до 100.
Попробуй угадать! (Для выхода введи 0)

Твой вариант: 50
Твое число БОЛЬШЕ загаданного. Попробуй еще раз.

Твой вариант: 25
Твое число МЕНЬШЕ загаданного. Попробуй еще раз.

Твой вариант: 37

Поздравляю! Ты угадал число 37!
Ты потратил(а) на это 3 попыток.
